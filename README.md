# Mi Pagina Web

Proyecto de tecnologias emergentes para aprender a usar Git y GitHub.

## Descripcion
Pagina web simple creada como ejercicio practico de control de versiones, mostrando el progreso a traves de 5 commits diferentes.

## Tecnologias usadas
- HTML5
- CSS3
- Git
- GitHub

## Historial de versiones
- Version 1: estructura basica de la pagina
- Version 2: seccion "Sobre mi"
- Version 3: estilos con CSS
- Version 4: menu de navegacion
- Version 5: formulario de contacto
